# SSVEP 当前会用到的参考文献阅读清单

这个文件是给人看的版本。JSON 只是给程序读取；你平时看这个 Markdown 就够了。

## 建议阅读顺序

1. **先看 CCA / FBCCA 基础**：理解当前 SSVEP 解码为什么用相关分析和滤波器组。
2. **再看 Nakanishi CCA 方法对比**：理解 IT-CCA、eCCA、template-assisted CCA 这些短预训练方法族。
3. **再看 TDCA / TRCA**：理解当前代码里 paper-aligned TDCA 和 TRCA 空间滤波的来源。
4. **最后看 idle / dynamic stopping / pseudo-online**：这些对应我们真正关心的异步控制指标，不只是离线准确率。
5. **数据集资料单独看 BETA 和 Wang2016**：它们是当前外部 benchmark / sanity / frequency selection 的来源。
