# Reference Materials

This folder stores small, shareable reference materials that should travel with
the GitHub repository.

Rules:

- Keep code in the normal source folders.
- Keep real datasets and generated run outputs under `datasets/`, `artifacts/`,
  or an external data disk, according to `.gitignore`.
- Keep papers, DOI/PubMed metadata, dataset source pages, and reading notes here
  when they are useful for onboarding or reproducing the project rationale.
- Do not add access-controlled publisher PDFs or unclear-license downloads.

Current collections:

- `SSVEP/`: curated references currently used by `02_SSVEP`, including a
  Chinese reading list, bibliography JSON, PubMed/Crossref metadata, BETA and
  Wang2016 dataset reference records, and openly shareable PDF material.
