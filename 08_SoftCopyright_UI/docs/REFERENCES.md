# UI And Software-Copyright References

This prototype uses two kinds of reference material.

## Software Copyright Materials

- Computer Software Protection Regulations: defines protected software as
  computer programs and related documentation.
- Measures for Computer Software Copyright Registration: records the registration
  workflow and software-identification material requirements.
- China Copyright Protection Center registration platform: practical submission
  entry for software copyright registration.

## UI Design Rationale

- Brain-computer interface software needs visible online state, confidence,
  idle/no-control handling, and feedback rather than a hidden classifier-only
  interface.
- Human-robot operation interfaces should show robot state, safety escalation,
  target validity, and operator override controls.
- This project is an operational control tool, so the UI uses a dense workbench
  layout instead of a marketing or landing-page layout.
