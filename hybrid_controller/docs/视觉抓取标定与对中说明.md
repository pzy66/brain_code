# 视觉抓取标定与闭环对中说明

当前机械臂摄像头按随臂移动处理，视觉抓取不再依赖一次远距离换算后直接抓取。

## 运行原则

- 检测层输出 `pixel_center` 和新的 `grasp_pixel`。`pixel_center` 是检测中心，`grasp_pixel` 是用于吸取的点，优先来自 `minAreaRect` 的稳定中心。
- 坐标层会先做去畸变，再计算 `camera_to_world_raw`。如果存在标定档案，会优先使用档案里的 `pixel_to_delta` 模型。
- `delta_servo` 模式下，如果 `grasp_pixel` 离 ROI 中心超过阈值，槽位会标记 `servo_required=true`，并拒绝直接 `PICK_WORLD`。
- 手动点 Pick 槽位时，如果槽位需要对中，程序会先发 `MOVE_CYL_AUTO`，等新画面回来后继续判断；收敛后才发最终抓取。
- 如果没有标定档案、档案图像尺寸不匹配、残差过高、抓取点质量太低，程序会拒绝自动抓取。

## 标定档案

默认路径：

```powershell
hybrid_controller\dataset\vision_calibration\current_profile.json
```

关键字段：

```json
{
  "profile_id": "eye-in-hand-current",
  "image_size": [640, 480],
  "K": [[...], [...], [...]],
  "D": [0, 0, 0, 0, 0],
  "pixel_to_delta": {
    "model": "affine",
    "matrix": [[...], [...]]
  },
  "residual": {
    "median_error_mm": 2.0,
    "p95_error_mm": 5.0,
    "max_error_mm": 6.0
  },
  "limits": {
    "max_allowed_error_mm": 6.0
  },
  "servo": {
    "center_tolerance_px": 8.0,
    "gain": 0.8,
    "max_attempts": 3
  }
}
```

## 从采样 CSV 生成 profile

CSV 需要包含：

```text
pixel_x,pixel_y,delta_x_mm,delta_y_mm
```

生成仿射模型：

```powershell
py -m hybrid_controller.tools.vision_calibration_profile `
  --samples-csv .\samples.csv `
  --output .\hybrid_controller\dataset\vision_calibration\current_profile.json `
  --model affine `
  --image-width 640 `
  --image-height 480
```

采样建议：用 5x5 或 7x7 覆盖可抓取工作区；每个点记录视觉检测到的像素点，以及机械臂当前位置到目标点的实际 `delta_x_mm/delta_y_mm`。
