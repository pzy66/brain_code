# 视觉抓取标定与对中说明

当前真机主线采用“高处选目标，低处相机中心对正，最终前伸 40 mm”的抓取策略。

## 摄像头链路

机械臂摄像头必须保持 Hiwonder 官方链路：

```text
usb_cam.service -> usb_cam_node -> /usb_cam/image_rect_color -> web_video_server:8080 -> PC
```

PC 端默认只读取这一条 URL：

```text
http://192.168.149.1:8080/stream?topic=/usb_cam/image_rect_color&type=mjpeg&width=640&height=480&quality=80
```

调试视觉和抓取时不要额外启动摄像头节点、扫描多个视频 URL、探测 `/dev/video*` 或重启 `usb_cam.service` / `web_video_server`。摄像头由 JetMax 系统默认拉起，PC 程序只消费官方 MJPEG topic。

## 当前对中策略

默认配置：

```text
vision_mode = robot_camera_detection
vision_mapping_mode = delta_servo
pick_tool_offset_source = command_bias
vision_eye_in_hand_pick_radius_bias_mm = 40.0
pick_cyl_radius_bias_mm = 0.0
vision_pick_target_pixel = None
```

流程：

```text
1. 搜索高度视野大，用 YOLO/轮廓结果选择目标。
2. 视觉伺服把目标移动到相机中心，也就是 alignment_target_pixel=(320,240)。
3. 下降到低处后继续按相机中心闭环对正。
4. 低处对正稳定后，最终 PICK_CYL 使用当前 theta/radius，并只加一次 +40 mm 半径前伸。
```

这个模式下，profile 里的 `servo.target_pixel` 不参与低处对中。不要再通过 `stage_models.confirm.servo.target_pixel` 补偿低高度漂移，否则会和“相机中心对正 + 40 mm 前伸”的机械策略冲突。

## 只允许一个前伸偏置入口

当前前伸偏置由 `vision_eye_in_hand_pick_radius_bias_mm=40.0` 提供，发生在视觉伺服决定最终 `PICK_CYL` 时。

`pick_cyl_radius_bias_mm` 必须保持 `0.0`，否则 GUI 发命令前会再次重写 PICK 命令，造成二次前伸。例子：

```text
正确：当前 radius=160 -> PICK_CYL theta 200
错误：当前 radius=160 -> 视觉加到 200 -> GUI 再加到 240
```

如果临时切回 `pick_tool_offset_source=target_pixel`，规则相反：使用 profile 的 `servo.target_pixel` 表示吸盘投影像素，最终抓取命令不得再叠加任何半径前伸。

## 视觉标定 profile

默认 profile：

```text
hybrid_controller/dataset/vision_calibration/current_profile.json
```

profile 仍然需要 `pixel_to_delta`，用于把像素误差转换成机械臂 XY/圆柱坐标移动量。当前主线中 top-level `servo.target_pixel=[320,240]` 只是兼容字段；低处实际目标由 `command_bias` 模式强制使用相机中心。

不要为当前主线写入 `stage_models.confirm.servo.target_pixel`。如果以后明确要恢复“吸盘投影像素对中”策略，必须同时把 `pick_tool_offset_source` 改回 `target_pixel`，并确认 `vision_eye_in_hand_pick_radius_bias_mm=0`、`pick_cyl_radius_bias_mm=0`。

## 调试顺序

```text
1. 先只读相机和识别，确认 pixel_center 与独立 HSV/轮廓中心一致。
2. 单步执行 MOVE_CYL 到搜索高度，确认目标进入中心附近。
3. 低处每次只执行一步下降或一步视觉伺服移动。
4. 到确认高度后，先看 dry-run 生成的最终 PICK_CYL 是否只比当前 radius 大 40 mm。
5. 只有确认命令正确后，才显式允许实际 PICK。
```

每次调参只改一个变量。摄像头链路、对中目标、最终前伸偏置不能混在一起同时改。
