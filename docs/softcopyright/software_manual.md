# 软件说明书草稿

## 软件名称

基于混合脑机接口的智能机械臂协同控制软件 V1.0

## 软件定位

本软件面向脑机接口辅助的人机协同控制场景，将运动想象（MI）、稳态视觉诱发电位（SSVEP）、视觉目标识别、机械臂安全执行和实验材料管理整合为一个可演示、可测试、可冻结的工程系统。V1.0 的重点不是新增所有算法能力，而是把已有模块整理为可申报的软件闭环。

## 主要功能

1. 数据采集管理：定位 MI 与 SSVEP 采集入口，展示数据保存路径、通道协议和可追溯要求。
2. 训练评估管理：展示 MI 分类器契约、SSVEP profile、视觉抓取 profile、模型基线和发布 gate。
3. 在线协同控制：表达键盘、MI、SSVEP 三类输入源的仲裁规则。键盘用于调试兜底，MI 输出连续移动意图，SSVEP 输出离散选择、确认和释放意图，低置信度统一进入 idle/no-control。
4. 视觉机械臂管理：读取视觉模型、抓取 profile、hybrid_controller 入口和配置状态。真实 MOVE/PICK/PLACE 动作继续保留在 hybrid_controller 的安全门控内。
5. 软著材料管理：展示说明书、用户手册、测试报告、源码交存清单、版本说明和引用材料的存在状态。

## 模块边界

- `08_SoftCopyright_UI`：软著 V1.0 演示工作台，负责只读状态展示、路径定位、命令预览和截图。
- `01_MI`：MI 数据采集、训练和实时推理模块。新分类器入库后需通过统一契约输出 profile。
- `02_SSVEP`：SSVEP 采集、短预训练、异步控制评估和 profile 管理模块。
- `hybrid_controller`：视觉识别、机械臂联动、机器人运行时通信和安全门控模块。
- `datasets/profiles`：发布后的 profile 根目录。真实训练权重默认不纳入源码交存。

## V1.0 交付目标

V1.0 应能在无 BrainFlow、无摄像头、无 JetMax 的环境下启动 UI 演示模式，完成软著截图、材料状态检查和核心流程说明。真实脑电采集与机器人动作作为验证材料补充，不作为 UI 启动前提。
